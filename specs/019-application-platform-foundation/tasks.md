# Checklist

- [x] Contrat universel : gouvernance, portées, permissions et fonctionnalités.
- [x] Déclaration d'application : lancement, icône, santé et compatibilité SDK.
- [x] Déclaration d'intégration : API, événements, webhooks et outils MCP.
- [x] Registre HTTP des applications publié et filtré par OpenFGA.
- [x] Permissions effectives normalisées dans la réponse du registre.
- [x] SDK étendu : applications, unité active, enfants organisationnels et télémétrie sûre.
- [x] Shell : surface Applications avec états complets et lancement gouverné.
- [x] Fondation de données existante auditée : contrats SemVer, schéma, qualité et rétention.
- [x] Contrat d'enregistrement : champs, relations, pièces jointes, rétention et droits fins.
- [x] Enveloppe d'événement commune et signature HMAC des webhooks.
- [x] Persistance des abonnements webhook et worker de livraison idempotent.
- [x] Template autonome d'application renforcé.
- [x] CI/CD économique du template, Infisical, santé et supervision.
- [ ] Publication du SDK étendu.
- [ ] KYA Forms enregistré comme première application réelle.
