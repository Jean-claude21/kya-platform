# Specification: Repository and documentation consolidation

## Objective

Make the implemented architecture obvious and mechanically protected before additional artifact
families and teams are added.

## Acceptance criteria

- English is the canonical language for maintained documentation and new specifications.
- The documentation portal builds strictly from versioned Markdown.
- Skill and MCP master templates expose their real required structure.
- Editable sources, templates and immutable releases have distinct locations.
- Domain and application dependency boundaries are tested automatically.
- Existing runtime behavior remains unchanged.
