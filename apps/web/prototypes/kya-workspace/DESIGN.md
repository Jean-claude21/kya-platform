## Overview

An independent, interactive proposal for the KYA-Platform home. A pale mineral-green navigation rail frames a white capability library. The active organization stays visible; details open in a focused side panel. The design prioritizes everyday discovery and access while keeping foundation administration available below the work area.

## Colors

KYA teal #1CA18C marks healthy state; deep green #0B5146 carries primary controls. Official orange #F99D32 identifies attention, yellow #E8E748 belongs to the brand palette, and coffee #875028 identifies restricted resources. The canvas is #F8FAF8, navigation #F0F5F1, text #172D28, and secondary text #62736B.

## Typography

Segoe UI Variable / Segoe UI / Arial. Page titles are 32px, section titles 17px, row titles 13–14px, body 14px and metadata 10–12px. Avoid large promotional statements and uppercase action labels.

## Layout

240px desktop navigation, 70px contextual topbar, 38px page gutters. The primary capability list occupies the flexible column and connections occupy a 300px rail. Below 1250px the rail stacks. Below 760px navigation becomes a dismissible drawer, rows reflow and state labels remain visible.

## Shapes and Components

Panels use 10px corners, controls 6px and icon tiles 8px. Fine borders identify grouping; most surfaces remain flat. Resources share comparable rows rather than isolated cards. Side dialogs display capability details and simulated connection paths; a centered dialog selects organization and unit. The official logo is reused without alteration.

## Interactions and Truth

Local interactions include search, type filters, favorites, context selection, capability details, environment selection, expandable administration and mobile navigation. Data is illustrative and all detail panels label that limitation. No credentials, service requests or production changes are made. Global application styles and the current React application are untouched by this proposal.

## Verification

Review desktop and mobile geometry, filtering, empty state, context selection, dialogs, keyboard escape, favorites and scroll. The prototype uses no third-party scripts, fonts or tracking.
